# Open-Redactor
--------Open-Redactor----------
Real-time PII (Personally Identifiable Information) redaction tool using AI + regex.

---Features---
Detects emails, phones, SSN, credit cards, names, locations, orgs
Web interface + REST API
Local processing (privacy-safe)
